# 提示工程项目：提示词优化工具

## 项目简介

一个提示词优化工具，支持 A/B 测试、版本管理、效果评估等。

## 功能特性

- 提示词模板管理
- A/B 测试对比
- 效果评估
- 版本历史

## 运行方式

```bash
pip install -r requirements.txt
python main.py
```

## 核心知识点

1. 提示词设计
2. A/B 测试
3. 效果评估
4. 版本管理
