# LLM 评估项目：自动化评估平台

## 项目简介

一个 LLM 自动化评估平台，支持批量评估、指标计算、报告生成等。

## 功能特性

- 批量评估
- 多指标计算
- 评估报告生成
- 结果可视化

## 运行方式

```bash
pip install -r requirements.txt
python main.py
```

## 核心知识点

1. 评估指标
2. 批量评估
3. 报告生成
4. 结果分析
