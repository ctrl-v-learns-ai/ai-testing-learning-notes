# NumPy Project 03: Image Processor (Matrix Operations)

## Project Overview
Process images using NumPy matrix operations. Images are just 2D/3D arrays!

## Features
- Load image as array
- Apply filters (blur, sharpen)
- Transform (rotate, flip)
- Adjust brightness/contrast

## How to Run
```bash
pip install numpy pillow
python main.py
```

## Core Concepts
1. Matrix operations
2. Image as array
3. Convolution filters
4. Array slicing for transforms
