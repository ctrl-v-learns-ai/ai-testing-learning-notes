# NumPy Project 01: Student Scores Manager

## Project Overview
Manage and analyze student exam scores using NumPy arrays.

## Features
- Store scores in 2D array (students x subjects)
- Calculate statistics (mean, max, min, std)
- Find top students
- Rank students by total score

## How to Run
```bash
python main.py
```

## Core Concepts
1. 2D array creation
2. Array indexing and slicing
3. Statistical functions
4. Sorting and ranking
