# 机器学习项目2：客户细分

## 项目简介

一个完整的客户细分项目，使用聚类算法将客户分成不同群体。

## 功能特性

- 数据预处理和探索
- 多种聚类算法对比
- 最佳聚类数选择
- 聚类结果可视化
- 客户画像分析

## 运行方式

```bash
pip install -r requirements.txt
python main.py
```

## 核心知识点

1. K-Means 聚类
2. 层次聚类
3. 轮廓系数
4. 肘部法则
