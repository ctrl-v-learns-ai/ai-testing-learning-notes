# 机器学习项目1：房价预测

## 项目简介

一个完整的房价预测项目，包括数据预处理、特征工程、模型训练、模型评估等。

## 功能特性

- 数据预处理和清洗
- 特征工程
- 多种回归模型对比
- 模型评估和可视化
- 预测结果输出

## 运行方式

```bash
pip install -r requirements.txt
python main.py
```

## 核心知识点

1. 线性回归
2. 特征工程
3. 模型评估
4. 交叉验证
