# Python 进阶项目1：重试装饰器

## 项目简介

一个通用的重试装饰器，支持配置重试次数、延迟时间、异常类型等。

## 功能特性

- 支持配置最大重试次数
- 支持指数退避延迟
- 支持指定重试的异常类型
- 支持重试回调函数
- 支持装饰器参数配置

## 运行方式

```bash
python main.py
```

## 核心知识点

1. 装饰器原理
2. functools.wraps
3. 带参数的装饰器
4. 异常处理
5. 类型提示
