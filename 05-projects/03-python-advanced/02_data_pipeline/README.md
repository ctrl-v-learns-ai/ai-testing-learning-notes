# Python 进阶项目2：数据处理管道

## 项目简介

一个基于生成器的数据处理管道，支持链式处理、过滤、转换等操作。

## 功能特性

- 基于生成器的惰性处理
- 支持链式操作
- 支持过滤、转换、聚合
- 支持大数据量处理
- 内存效率高

## 运行方式

```bash
python main.py
```

## 核心知识点

1. 生成器原理
2. yield from 语法
3. 管道模式
4. 惰性求值
5. 内存优化
