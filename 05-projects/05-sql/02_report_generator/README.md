# SQL 项目2：报表生成器

## 项目简介

一个基于 SQL 的报表生成器，支持多表查询、数据聚合、报表导出等。

## 功能特性

- 多表关联查询
- 数据聚合统计
- 报表格式化输出
- 导出为 CSV/Excel

## 运行方式

```bash
python main.py
```

## 核心知识点

1. SQL 多表连接
2. GROUP BY 分组聚合
3. 窗口函数
4. 报表设计
