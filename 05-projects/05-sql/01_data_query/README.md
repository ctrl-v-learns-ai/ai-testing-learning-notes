# SQL 项目1：数据查询工具

## 项目简介

一个基于 SQLite 的数据查询工具，支持创建表、插入数据、执行查询等。

## 功能特性

- 创建和管理 SQLite 数据库
- 执行 SQL 查询
- 数据导入导出
- 查询结果格式化输出

## 运行方式

```bash
python main.py
```

## 核心知识点

1. SQLite 数据库操作
2. SQL 基本查询
3. Python sqlite3 模块
4. 数据导入导出
