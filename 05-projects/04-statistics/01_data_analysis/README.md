# 统计学项目1：数据分析工具

## 项目简介

一个完整的数据分析工具，支持描述性统计、数据可视化、异常值检测等。

## 功能特性

- 描述性统计分析
- 数据分布分析
- 异常值检测
- 相关性分析
- 数据可视化

## 运行方式

```bash
pip install -r requirements.txt
python main.py
```

## 核心知识点

1. 描述性统计
2. 概率分布
3. 异常值检测
4. 相关性分析
5. 数据可视化
