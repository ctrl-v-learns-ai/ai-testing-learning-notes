# 统计学项目2：A/B 测试分析工具

## 项目简介

一个完整的 A/B 测试分析工具，支持假设检验、效应量计算、置信区间等。

## 功能特性

- 两组数据对比分析
- t 检验（单样本、双样本、配对）
- 卡方检验
- 效应量计算
- 置信区间
- 结果可视化

## 运行方式

```bash
pip install -r requirements.txt
python main.py
```

## 核心知识点

1. 假设检验
2. t 检验
3. 效应量
4. 置信区间
5. p 值解释
