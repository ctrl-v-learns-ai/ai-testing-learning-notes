# 深度学习项目1：MNIST 手写数字分类

## 项目简介

使用 CNN 实现 MNIST 手写数字分类，包括数据加载、模型训练、模型评估等。

## 功能特性

- 数据预处理和增强
- CNN 模型构建
- 模型训练和评估
- 结果可视化

## 运行方式

```bash
pip install -r requirements.txt
python main.py
```

## 核心知识点

1. CNN 架构
2. 图像分类
3. 模型训练
4. 模型评估
