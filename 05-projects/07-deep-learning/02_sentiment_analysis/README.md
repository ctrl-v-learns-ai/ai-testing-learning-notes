# 深度学习项目2：情感分析

## 项目简介

使用 RNN/LSTM 实现文本情感分析，包括文本预处理、模型训练、模型评估等。

## 功能特性

- 文本预处理
- 词嵌入
- LSTM 模型
- 情感分类

## 运行方式

```bash
pip install -r requirements.txt
python main.py
```

## 核心知识点

1. 文本预处理
2. 词嵌入
3. RNN/LSTM
4. 文本分类
