# AI 测试方法项目：测试用例生成器

## 项目简介

一个 AI 驱动的测试用例生成器，支持自动生成测试用例、测试数据等。

## 功能特性

- 测试用例自动生成
- 测试数据生成
- 边界条件分析
- 测试覆盖率分析

## 运行方式

```bash
pip install -r requirements.txt
python main.py
```

## 核心知识点

1. 测试用例设计
2. 边界值分析
3. 等价类划分
4. 自动化测试
