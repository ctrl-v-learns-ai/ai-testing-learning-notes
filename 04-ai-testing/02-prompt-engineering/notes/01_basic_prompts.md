# 提示工程一：基础提示技巧

## 什么是提示工程？

提示工程是设计和优化提示词，以从 AI 模型获得最佳输出的技术。

类比理解：
- 提示工程 = 和 AI 对话的艺术
- 好的提示 = 清晰的指令 = 更好的结果

## 提示的基本结构

```
[角色设定] + [任务描述] + [输入数据] + [输出格式]
```

### 示例

```python
# 基础提示
prompt = "请翻译以下句子为英文：今天天气很好"

# 结构化提示
prompt = """
你是一位专业的翻译人员（角色设定）
请将以下中文句子翻译成英文（任务描述）
要求：保持原意，语法正确（输出格式）

句子：今天天气很好
"""
```

## 提示技巧

### 1. 明确角色设定

```python
# 不好的提示
prompt = "写一段代码"

# 好的提示
prompt = """
你是一位资深的 Python 开发工程师，擅长编写清晰、高效的代码。
请写一个函数，实现以下功能：
- 输入：一个整数列表
- 输出：列表中所有偶数的平方和
- 要求：使用列表推导式，添加类型提示
"""
```

### 2. 提供具体示例

```python
# 不好的提示
prompt = "生成一些测试用例"

# 好的提示
prompt = """
请为以下函数生成测试用例：

def add(a: int, b: int) -> int:
    return a + b

请按照以下格式输出：
1. 测试用例名称
2. 输入参数
3. 预期输出
4. 测试目的

示例：
- 测试用例：测试正数相加
- 输入：a=2, b=3
- 预期输出：5
- 测试目的：验证基本加法功能
"""
```

### 3. 使用分隔符

```python
# 使用分隔符清晰标记输入
prompt = """
请分析以下代码的潜在问题：

---代码开始---
def divide(a, b):
    return a / b
---代码结束---

请指出：
1. 可能的异常情况
2. 改进建议
"""
```

### 4. 指定输出格式

```python
# JSON 格式
prompt = """
请将以下信息提取为 JSON 格式：

张三，25岁，北京，工程师

输出格式：
{
  "name": "姓名",
  "age": 年龄,
  "city": "城市",
  "job": "职业"
}
"""

# Markdown 格式
prompt = """
请用 Markdown 表格格式列出 Python 常用数据类型：

| 类型 | 说明 | 示例 |
|------|------|------|
"""
```

### 5. 限制输出长度

```python
# 指定长度
prompt = "请用100字以内解释什么是机器学习"

# 指定数量
prompt = "请列出5个 Python 常用的内置函数"
```

## 常见提示模式

### 1. 零样本提示（Zero-shot）

```python
prompt = "请将以下句子分类为正面或负面：这部电影很好看"
```

### 2. 少样本提示（Few-shot）

```python
prompt = """
请将句子分类为正面或负面：

句子：今天天气真好
分类：正面

句子：这部电影太无聊了
分类：负面

句子：这个餐厅的菜很好吃
分类：
"""
```

### 3. 思维链提示（Chain of Thought）

```python
prompt = """
请逐步解决以下问题：

问题：一个商店有 15 个苹果，卖掉了 8 个，又进了 12 个，现在有多少个？

请按步骤思考：
1. 初始数量
2. 卖掉后的数量
3. 进货后的数量
4. 最终答案
"""
```

### 4. 自我一致性（Self-Consistency）

```python
prompt = """
请用三种不同的方法解决以下问题，并给出最终答案：

问题：计算 1 到 100 的和

方法一：直接相加
方法二：高斯公式
方法三：编程实现
"""
```

## 提示优化技巧

### 1. 迭代优化

```python
# 第一次尝试
prompt1 = "写一个排序函数"

# 第二次优化
prompt2 = """
写一个 Python 排序函数，要求：
1. 使用快速排序算法
2. 支持自定义比较函数
3. 添加类型提示
4. 添加文档字符串
"""

# 第三次优化
prompt3 = """
写一个 Python 快速排序函数，要求：
1. 使用快速排序算法
2. 支持自定义比较函数（通过 key 参数）
3. 添加类型提示
4. 添加文档字符串，包含参数说明和示例
5. 处理空列表和单元素列表的边界情况
"""
```

### 2. 使用约束条件

```python
prompt = """
请生成一个用户注册表单的 HTML 代码，要求：

约束条件：
1. 必须包含：用户名、邮箱、密码、确认密码
2. 密码必须包含大小写字母和数字
3. 邮箱必须符合格式
4. 添加前端验证
5. 使用 Bootstrap 样式

请确保代码可以直接运行。
"""
```

## 常见坑

### 坑1：提示太模糊

```python
# 不好的提示
prompt = "帮我写代码"

# 好的提示
prompt = """
请写一个 Python 函数，功能如下：
- 函数名：is_palindrome
- 输入：一个字符串
- 输出：布尔值，表示是否是回文
- 要求：忽略大小写和空格
"""
```

### 坑2：没有提供上下文

```python
# 不好的提示
prompt = "这个错误怎么解决？"

# 好的提示
prompt = """
我在使用 Python 读取 CSV 文件时遇到以下错误：

错误信息：UnicodeDecodeError: 'utf-8' codec can't decode byte 0xb0

代码：
df = pd.read_csv('data.csv')

请帮我分析原因并提供解决方案。
"""
```

### 坑3：期望一步到位

```python
# 不好的做法：一次要求太多
prompt = "写一个完整的电商系统"

# 好的做法：分步骤
prompt1 = "先设计数据库表结构"
prompt2 = "实现用户注册登录功能"
prompt3 = "实现商品管理功能"
```
