## 高级提示技巧

### 1. 角色扮演提示

```python
# 多角色对话
prompt = """
请模拟以下场景的对话：

角色A：资深测试工程师，经验丰富，注重细节
角色B：初级开发工程师，刚入职，需要指导

场景：角色B提交了一个有bug的代码，角色A进行代码审查

请生成5轮对话，展示如何专业地指出问题并给出建议。
"""
```

### 2. 反思提示（Self-Reflection）

```python
prompt = """
请完成以下任务：

## 提示模板设计

### 1. 通用模板

```python
class PromptTemplate:
    def __init__(self, role, task, constraints, output_format):
        self.role = role
        self.task = task
        self.constraints = constraints
        self.output_format = output_format
    
    def render(self, **kwargs):
        return f"""
角色：{self.role}
任务：{self.task}
约束：{self.constraints}
输出格式：{self.output_format}

输入：{kwargs.get('input', '')}
"""
```

### 2. 测试用例生成模板

```python
test_case_template = """

功能描述：{function_description}
输入参数：{parameters}
预期行为：{expected_behavior}

要求：
1. 覆盖正常场景
2. 覆盖边界条件
3. 覆盖异常场景
4. 每个用例包含：名称、前置条件、输入、预期输出、测试目的

请以表格形式输出。
"""
```

### 3. 代码审查模板

```python
code_review_template = """
你是一位资深的代码审查专家，请审查以下代码：

---代码开始---
{code}
---代码结束---

请从以下维度审查：

1. 功能正确性
   - 代码是否实现了预期功能
   - 是否有逻辑错误

2. 代码质量
   - 命名是否规范
   - 是否有重复代码

4. 安全性
   - 是否有安全漏洞
   - 是否有注入风险

5. 可维护性
   - 代码是否易于理解
   - 是否易于扩展

请给出：
- 问题列表（按严重程度排序）
- 改进建议
- 重构示例（如果需要）
"""
```

## 实际应用场景

### 1. 测试用例生成

```python
def generate_test_cases(function_code):
    prompt = f"""
    你是一位资深测试工程师。
    
    请为以下函数生成测试用例：
    
    ```python
    {function_code}
    ```
    
    要求：
    1. 覆盖正常场景（至少3个）
    2. 覆盖边界条件（至少2个）
    3. 覆盖异常场景（至少2个）
    
    输出格式：
    | 编号 | 场景类型 | 输入 | 预期输出 | 测试目的 |
    """
    return prompt
```

### 2. 缺陷报告生成

```python
def generate_bug_report(description):
    prompt = f"""
    请根据以下描述生成标准的缺陷报告：
    
    描述：{description}
    
    输出格式：
    - 缺陷标题：
    - 严重程度：P0/P1/P2/P3
    - 所属模块：
    - 复现步骤：
    - 预期结果：
    - 实际结果：
    - 环境信息：
    - 附件：
    """
    return prompt
```

### 3. 代码重构建议

```python
def suggest_refactoring(code):
    prompt = f"""
    请分析以下代码，给出重构建议：
    
    ```python
    {code}
    ```
    
    请从以下角度分析：
    1. 代码异味
    2. 重复代码
    3. 复杂度过高
    4. 命名不规范
    
    给出：
    - 问题列表
    - 重构建议
    - 重构后的代码
    """
    return prompt
```
